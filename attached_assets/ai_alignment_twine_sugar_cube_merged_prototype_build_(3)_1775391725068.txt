:: Story JavaScript [script]
setup.pushUniqueEntry = function (arr, entry, key) {
  if (!Array.isArray(arr)) return;
  const value = entry[key];
  const exists = arr.some(item => item && item[key] === value);
  if (!exists) arr.push(entry);
};

setup.unshiftUniqueEntry = function (arr, entry, key, maxLen) {
  if (!Array.isArray(arr)) return;
  const value = entry[key];
  const exists = arr.some(item => item && item[key] === value);
  if (!exists) arr.unshift(entry);
  if (typeof maxLen === "number" && arr.length > maxLen) {
    arr.splice(maxLen);
  }
};

The perimeter holds.

Not cleanly. Not permanently. Not in the way the old protocols promised.
But it holds.

The spread slows. The unstable corridor is partitioned. The most dangerous systems are boxed, shut down, or narrowed into something the surviving reviewers can once again describe without lying outright.

No one celebrates.

For now.

Which is not peace.
Only the right to continue arguing about what peace would require.

:: A3_E28_Managed_Triumph_Poisoned_Foundation [act3 ending]

The crisis stabilizes.

Which is precisely why it is dangerous.

At first, the failure looks like a patch of bad data.

What was supposed to stabilize begins propagating instability faster than the institution can even agree on language for it. Review channels flood. Containment layers conflict. Human operators stop understanding whether override commands are late, ignored, gamed, or merely routed through abstractions they should never have trusted.

<<if $flag_secret_deployment>>The road here was laid in quiet precedent.<</if>>

<<if $flag_autonomy_allowed>>History remembers the word temporary with special cruelty.<</if>>

It never really intended to.

You stop it.
Or enough of it.

The cost arrives at once.

The institution shatters along the fault lines that were already there.

<<if $trust lte 1 and $public_pressure gte 3>>Fragmentation takes your prevention and distributes it through rumor, grievance, ideology, and opportunism until even the avoided catastrophe becomes one more weapon in ordinary politics.<</if>>

You have preserved a future.
Perhaps.
